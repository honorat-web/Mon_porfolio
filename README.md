# Site personnel — KOUGBAHOUE Honorat Harold

## Présentation

Ce projet est un site web personnel statique pour **KOUGBAHOUE Honorat Harold**.

Il présente brièvement son profil d'étudiant en deuxième année de classe préparatoire, sa passion pour l'informatique, ainsi qu'une section dédiée à ses projets. Le site permet également d'accéder directement au contact téléphonique.

Le site est réalisé avec **HTML et CSS**, sans serveur ni base de données.

## Comment ouvrir le site

Aucune installation n'est nécessaire.

1. Placez tous les fichiers du projet dans le même dossier.
2. Ouvrez **`index.html`** dans un navigateur web (Chrome, Firefox, Edge, Safari, etc.).
3. Utilisez la barre de navigation pour accéder aux différentes pages.

> **Important :** les fichiers HTML et `style.css` doivent rester dans le même dossier afin que les pages utilisent correctement la feuille de style et que les liens entre les pages fonctionnent.

## Structure du projet

```text
site-personnel/
├── index.html
├── a-propos.html
├── projets.html
├── style.css
└── README.md
```

### Description des fichiers

- **`index.html`** : page d'accueil avec le nom, une brève présentation et les liens de navigation.
- **`a-propos.html`** : page « À propos » avec des informations supplémentaires sur le profil et la formation.
- **`projets.html`** : page « Projets », actuellement en construction.
- **`style.css`** : feuille de style commune aux trois pages HTML.
- **`README.md`** : documentation du projet et instructions d'utilisation.

## Navigation

Les trois pages HTML sont reliées par une barre de navigation commune :

- **Accueil**
- **À propos**
- **Projets**
- **Contact**

Le lien **Contact** permet de lancer directement un appel vers le numéro indiqué sur le site.
