# Site personnel — KOUGBAHOUE Honorat Harold

Site web personnel statique réalisé en HTML et CSS.

## Ouvrir le site

Aucune installation n'est nécessaire. Placez tous les fichiers dans le même dossier, puis ouvrez **`index.html`** dans un navigateur.

## Structure

```text
site-personnel-ameliore/
├── index.html
├── a-propos.html
├── projets.html
├── style.css
└── README.md
```

La feuille `style.css` est commune aux trois pages. La photo fournie n'est volontairement pas utilisée pour le moment, conformément aux consignes.
